# 指间 / Keyboard Launcher

A Windows desktop launcher that maps applications and actions to physical keyboard positions. Users invoke it through a configurable keyboard shortcut or double tap, then launch by key or click. Frequent use should feel immediate and predictable.

## Product truth

- Supports applications, URLs, script files, files, folders and keyboard shortcut actions. Existing command bindings remain supported.
- Supports Chinese and English, system/light/dark themes, paging, editing, drag/swap and removal.
- Settings persist automatically; binding editor changes remain drafts until Save.
- Local installation and Microsoft Store distribution have different update and licensing paths.

## Brand commitment

Preserve the established keyboard appearance, with complete, legible keycaps and recognizable physical positions. Improve interaction details within that appearance. Any new visual direction must be reviewed as a concrete preview before it replaces the running version.

## Constraints

Preserve user configuration, physical binding positions, invocation behavior, focus restoration, startup preference, one canonical local installation directory and the permanent tray identity. UI work must not rewrite custom names or icons. Follow windows/AGENTS.md for deployment and testing.
